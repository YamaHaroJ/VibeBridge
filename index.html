How it works

Your normal conversation, with more context.

VibeBridge is designed to fit around the way you already work with ChatGPT.

STEP 01

Connect your Mac

Install the local agent and load the Chrome extension using the published setup guide. You approve the required setup and permissions.

Privacy

Your project context stays under your control.

VibeBridge uses local repository files, Git metadata, and notes explicitly saved for a project. It does not read private history from previous ChatGPT conversations. The local agent listens on loopback and requires a bearer token. Do not store credentials or private customer data in project memory.

FAQ

Know what it does—and what it doesn’t.

Does VibeBridge read my previous private ChatGPT conversations?

No. Continuity is based on repository files, Git metadata, project memory, and notes explicitly saved through VibeBridge. It does not read private history from other conversations.

Does it run commands on my Mac?

The project includes an explicitly approved command-relay design for supported local operations. Local execution is powerful; only authorize it on a Mac and projects you control. Do not assume every command-relay feature is fully verified on every build.

Is it a one-click install yet?

Not fully. The current setup uses a guided macOS installer and a Chrome unpacked-extension flow. Chrome Web Store publication and signed/notarized macOS packaging are still distribution steps.

Where do I get the software and setup instructions?

Installation instructions and a permanent direct download will be published in the installation section when ready.

VibeBridge is an evolving developer tool. Features and installation steps can change; check the current README and release notes before installing.
