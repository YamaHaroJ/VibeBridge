Connect your Mac

VibeBridge uses a private local token so the Chrome extension can securely talk to the VibeBridge agent running on this Mac.

What this means for your privacy

The token is generated by the local agent and stays on this Mac. VibeBridge does not need your GitHub password or ChatGPT password.

When you use project checkpointing, project summaries may be saved to the relevant GitHub repository. That is separate from the local token. The extension cannot promise that all project information stays private if you choose a public repository.
